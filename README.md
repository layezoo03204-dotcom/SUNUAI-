Installation
Installer Node.js.
Ouvrir ce dossier dans un terminal.
Exécuter npm install.
Copier .env.example vers .env.
Ajouter votre clé API dans .env.
Exécuter npm start.
Ouvrir http://localhost:3000.
Sécurité
Ne mettez jamais OPENAI_API_KEY dans index.html, script.js ou un dépôt public. Le fichier .env est ignoré par Git.
La connexion utilise la Responses API, recommandée pour les nouvelles intégrations# SUNUAI-
